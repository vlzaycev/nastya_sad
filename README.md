# Сюрприз для Насти ❤️

Одностраничная страничка, чтобы поднять настроение, когда грустно.
Чистые HTML + CSS + JS, без сборки и зависимостей (кроме Google Fonts).

```
index.html   — разметка
style.css    — стили и анимации
script.js    — логика; все тексты, фразы и цвета — в объекте CONFIG в начале файла
assets/      — photo.jpg (фото) и music.mp3 (необязательно)
```

## Как поменять содержимое
Открой `script.js` и отредактируй `CONFIG`: заголовок, послание, подпись,
ласковые фразы, пути к фото/музыке, цвета.

## Запуск локально
Просто открой `index.html` двойным кликом.
Или запусти мини-сервер в папке проекта: `python3 -m http.server 8000`, затем открой http://localhost:8000.

## Как выложить бесплатно
- **Netlify Drop:** зайди на https://app.netlify.com/drop и перетащи туда всю папку проекта — через несколько секунд будет ссылка.
- **GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save.
  Через минуту страница будет доступна по адресу `https://<логин>.github.io/nastya_sad/`.

Учти: на GitHub Pages сайт публичный, даже если сам репозиторий приватный (приватные Pages доступны только на платных тарифах).
