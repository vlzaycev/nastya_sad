# Папка для файлов

- `photo.jpg` — ваше совместное фото (лучше квадратное или близкое к квадрату, ~1000×1000 px, до 500 КБ).
  Пока файла нет, на странице показывается красивая заглушка.
- `music.mp3` — необязательная фоновая музыка. Если файла нет, кнопка музыки просто не появится.
  Музыка никогда не включается сама — только по нажатию.

Другие имена файлов можно указать в `CONFIG` в начале `script.js`.
